# Country Information System Using OOP

## About the Project

This is a Python-based Country Information System developed using Object-Oriented Programming (OOP) concepts.

The program allows users to select a country and view information about its states or regions.

## Countries Covered

- India
- USA
- Russia
- Japan

## Features

- Display available countries
- Display states or regions of the selected country
- View information about selected states or regions
- Menu-driven user interaction

## OOP Concepts Used

- Classes and Objects
- Inheritance
- Constructor
- Methods

## Technologies Used

- Python
- Object-Oriented Programming (OOP)
